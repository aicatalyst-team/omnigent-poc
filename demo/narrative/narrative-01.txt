In this demo we want to introduce an exciting new open source project called onmi gent.

It can be described as a meta-harness for AI agents. It originated from Databricks but has a growing community now, including many contributions from Red Hat.

It acts as a common layer over Claude Code, Codex, Pi, and the agents you write yourself, avoiding the vendor lock-in of the harnesses from the big labs.

You might ask: how is different from OpenCode? What's new here? 

The difference is that Omni Gent runs the actual harness in the background, so you still get access to all of its functionality and special commands.

But there's even more to it when we start using Omni Gent it in server mode. This allows us to share agent sessions with others in a team.
